# 随时有效推断：构造、假设与审计规则

本模块（`app.seqmath` / `app.spec` / `app.engine` / `app.ledger` / `app.anytime`）在现有
试点分配与结果汇总之上提供**随时有效（anytime-valid）**的推断：每周或任意频率查看，
效果区间与停止依据都保持有效，反复查看不会把偶然波动当成改善。

## 1. 估计目标与截顶含义

目标是**截顶尺度上逐企业处理效应的累计平均**：

    τ̄_t = (1/t) Σ_{i≤t} τ_i,  τ_i = E[cap(Y_i(1))] − E[cap(Y_i(0))]

其中 cap 为方案冻结的业务截顶范围 [low, high]。区间与停止决定解释的是**截顶后结果**
的效应，不外推未截顶尺度；每次查看报告 `capped`（被截顶的观测数），截顶比例高时
应回到业务上讨论目标含义，而不是悄悄换掉目标。

## 2. 构造

**IPW 得分**（使用结果出现前已知的实际分配概率，处理非等概率分配）：

    G_i = T_i·Y_i/p_i − (1−T_i)·Y_i/(1−p_i),  E[G_i] = τ_i

Y_i∈[low,high] 时 G_i∈[ℓ_i,u_i]（`seqmath.score_bounds`），半宽 b_i=(u_i−ℓ_i)/2，
V_t=Σb_i²。由 Hoeffding 引理，G_i−τ_i 是条件 sub-Gaussian 的鞅差。

**置信序列**（正态混合 Hoeffding 边界，Howard–Ramdas–McAuliffe–Sekhon 2021，
`seqmath.mixture_radius`）：

    P(∃t: |Σ(G_i−τ_i)| ≥ √( 2(V_t+ρ²)(ln(2/α) + ½ln(1+V_t/ρ²)) )) ≤ α

除以 t 即得 τ̄_t 的区间。ρ² 是冻结的尺度参数，只影响宽度不影响有效性。
这不是"把固定时点正态区间连成曲线"：边界由混合上鞅的 Ville 不等式给出，
对任意查看次数与停止时间一致有效。

**随时 p 值**（`seqmath.log10_anytime_p`）：弱原假设"累计平均效应为 0"，
p_t≤α 当且仅当 0 落在 α 级置信序列之外。

**检验鞅**（`seqmath.log10_test_martingale`）：L_t=exp(λS_t−λ²V_t/2)，λ 在方案中
冻结。它在**尖锐原假设**（每个企业效应均≤0）下是非负上鞅，作为补充证据报告；
停止决定一律以置信序列为准（弱原假设、与估计对齐）。

**停止规则**（冻结于方案）：区间整体高于 δ 判 `benefit`，整体低于 −δ 判 `harm`；
两个方向共用同一 α_cell，区间已联合覆盖，无需额外校正。

## 3. 适用假设

1. 企业级随机分配，且给定历史时每个企业的分配概率已知、满足 p_i∈[p_min, 1−p_min]
   （正性/重叠）；分配在结果出现前完成并登记。
2. 结果有界：连续结果按业务预定范围截顶，截顶范围先于结果冻结在方案里。
3. 无干扰（SUTVA）：企业之间互不影响；企业顺序、指标、分组、权重在结果可知前冻结。
4. 更正以更高 revision 到达（沿用 catalog 的修订快照语义）。

假设被破坏时模块**不静默继续**：对应单元在首个违规企业处阻塞并报告原因
（`PROPENSITY_OUT_OF_BOUNDS`、`OUTCOME_PREDATES_FREEZE` 等）。

## 4. 多重性与权重预算

- 每个预登记单元（指标×分组）分得 Bonferroni 份额 α_cell = α_total·w_cell，Σw≤1；
  家族级结论：任一单元发生错误停止的概率 ≤ α_total。指标/分组子预算在运行报告的
  `budget` 中可见。
- **时间维度不花费预算**：置信序列对任意查看次数有效，每周看与每分钟看结论同级。
- **事后新增分组**两条路，都不能借用已分配的错误概率：
  - `run --explore`：探索性单元，α=None，区间标注"无随时有效保证"，**不能触发停止**；
  - `amend`：从**剩余**预算中分配权重正式登记，`effective_from` 必须晚于已查看数据
    的 as_of，且只消费该时点之后到达的结果（前向生效，不能回溯）。

## 5. 延迟、顺序与前缀

企业按预登记 `order` 连续消费。首个不完整企业（结果未到、登记未到、概率越界、
上报冲突等）阻塞该单元；阻塞点之后结果已返回的企业列入 `waiting_behind` 仅供
审计，**不得提前消费**——不能先挑已经返回的好结果。不同指标的完整度分别维护，
因此各单元前缀可以不同。

## 6. 版本、更正与决定

- 每次运行产生一个版本并入哈希链：`compute`（新输入）、`repeat`（内容相同的重复
  上报，同样入链可审计）、`rejected`（无效输入，原因入链）。输入快照按内容寻址
  存于 `objects/`。
- 停止决定写入 `decisions.jsonl` 后**不可变**。更正资料产生新版本；若更正使历史
  决定在当时前缀上不再成立（`CONDITION_NOT_REPRODUCED`）或前缀本身改变
  （`PREFIX_CHANGED`），新版本在 `conflicts` 中报告，须 `acknowledge` 显式确认；
  原决定记录始终保留，不会无声改变。
- `replay N` / `replay --all` 从内容寻址对象重算任意时点的单元状态、决定与冲突，
  并校验哈希链；任何篡改都会在校验中暴露。

## 7. 数值

所有证据量在对数空间累计与报告（`log10_anytime_p`、`log10_test_martingale`）。
逐因子连乘在浮点下溢后会把证据"变成 0"，对数空间不会：测试模拟 20 万步连乘，
朴素乘积下溢到不可用，对数证据仍精确（`tests/test_seqmath.py`）。区间端点不可
表示时（空前缀）输出 null 而不是 inf，保证 JSON 严格合法。

## 8. 局限

- Hoeffding 界偏保守（宽度 ~ b·√(log t / t)），IPW 得分范围宽时需要的样本量较大；
  更紧的经验 Bernstein 类构造可作为后续扩展，有效性论证结构相同。
- 检验鞅只对尖锐原假设有效；关于累计平均的结论以置信序列与随时 p 值为准。
- 分组属性取自分配记录，必须在分配时已知；属性更正会改变前缀并触发冲突报告。
